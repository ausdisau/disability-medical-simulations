# Disability Medical Simulations Moodle Theme

## Purpose

Accessible Moodle theme foundation for disability medical simulation education.

## Design principles

- Person-first clinical learning.
- Baseline-aware assessment.
- Communication access as safety infrastructure.
- Evidence-gated simulation controls.
- Non-punitive learning branches.
- Accessibility-first interface design.

## Visual system

Primary navy: #0D2340
Clinical blue: #1E67A8
Communication teal: #147D78
Focus yellow: #FFBF47

## Intended Moodle integration

Designed as a Boost child theme foundation for:

- H5P activities.
- Scenario-based simulations.
- Accessible audio and transcript resources.
- Course completion tracking.
- Moodle LMS delivery.

## Safety boundary

This theme supports educational simulation. It does not certify clinical competence or provide procedural instructions.
