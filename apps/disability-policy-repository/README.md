# Disability Policy Repository — Next.js prototype

This prototype implements the public-interface concepts from the Australian Disability Policy Compendium blueprint and connects them to the Accessible Futures Clinical Simulation Lab.

## Included

- Explore / Track / Compare / Ask / Act policy modes
- Explicit evidence states: CANONICAL / PROBABLE / CANDIDATE / RESEARCH
- Provenance-first editorial framing
- Accessible responsive UI
- Simulation Lab scenario index for AF-001 to AF-004
- No patient-identifiable data and no live clinical decision support

## Run

```bash
npm install
npm run dev
```
